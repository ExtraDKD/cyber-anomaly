# Cyber Anomaly · โต๊ะสืบมิจฉาชีพ

เกมจำลองสถานการณ์ฝึกรับมือมิจฉาชีพออนไลน์และภัยไซเบอร์ เล่นบนเว็บเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้ง

ผู้เล่นรับบท **"ต้น"** เจ้าหน้าที่กะดึกของบริษัทตรวจภัยไซเบอร์ในเมืองเล็ก ๆ ทำงานร่วมกับ **พี่ท็อป** อดีตตำรวจไซเบอร์ ต้องช่วยชาวบ้านตรวจข้อความ อีเมล เว็บ แอป และข่าวที่ส่งเข้ามา ว่าเป็นมิจฉาชีพหรือของจริง ภายในเวลา 7 คืน

## วิธีเล่น

* เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages
* อ่านเรื่องของผู้ร้องและหลักฐาน แล้วปักธงจุดที่ผิดสังเกต
* กด 📋 เพื่อคัดลอกลิงก์ อีเมล เลขบัญชี หรือเบอร์โทร ไปตรวจในโปรแกรมบนเดสก์ท็อป
* ตัดสินว่า "โดนหลอก / ปลอดภัย / ก่อกวน" หรือ "ข่าวปลอม / ข่าวจริง / ข่าวบิดเบือน"
* ตั้งแต่คืนที่ 3 ต้องเฝ้าระวังแจ้งเตือนความปลอดภัยที่จอ SOC ไปพร้อมกัน

## ฟีเจอร์

* 152 เคส ใน 10 หมวดภัย พร้อมเคสข่าวปลอมและข่าวบิดเบือน
* โปรแกรมตรวจ 6 ตัว: ตรวจโดเมน, เช็กบัญชีม้า, โทรยืนยัน, RiskScan, ตรวจข่าว, SafeScan
* ระบบ SOC พร้อมแจ้งเตือน 14 รูปแบบ และคู่มือ SOC
* เนื้อเรื่อง บทสอนแบบลงมือทำ ค่าสติ ร้านอัปเกรด และหน้าสรุปผลรายคืน

## เทคโนโลยี

HTML, CSS และ JavaScript ล้วนในไฟล์เดียว ไม่ใช้ไลบรารีภายนอก

## เครดิต

* แนวคิด เนื้อเรื่อง และภาพตัวละคร: นายกิตติพงศ์ คงสมปราชญ์ และ นส.นัยน์ภัค หงศ์หา
* โค้ดและเนื้อหาพัฒนาร่วมกับผู้ช่วย AI (Claude โดย Anthropic) ภายใต้การกำกับของผู้พัฒนา
